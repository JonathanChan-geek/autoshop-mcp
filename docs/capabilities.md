# 0.3 能力与验证边界

## 已实现

| 场景 | 工具 | 结果如何确认 |
| --- | --- | --- |
| 检查工程、读指令 | project_inspect / il_read | 校验文件结构、登记信息和哈希 |
| 查常数、信号、注释原文 | project_search | 返回原文件行号和上下文；字面匹配 |
| 查信号在何处读写 | project_xref | 显式地址匹配，已识别指令分类，未知项明确返回 |
| 找重复线圈、跨块写入 | project_audit | 返回复核位置，不推断实际扫描条件 |
| 导出供人工或 AI 审查 | project_export | UTF-8 文本、来源文件名/哈希、覆盖范围及 JSON 结果 |
| 单处或批量修改 | il_patch_copy / il_batch_patch_copy | 哈希防误改、唯一匹配、禁止重叠、新副本、配置保留 |
| 单块或整工程 LD 转 IL | ld_to_il_copy / project_convert_all_copy | 原厂转换，每次转换前后重新编译机器码相同 |
| 完成修改、编译和打包 | project_build_copy | 失败只留下诊断，成功交付最终工程和编译包 |

## 分析范围

`complete_source_coverage` 表示已登记程序块是否都可读成 IL，**不是指令语义全部覆盖**。`project_xref` 的 `indirect_and_implicit_coverage` 始终为 false，不能用来证明一个寄存器未使用。

当前读写分类仅覆盖代码中明确列出的接点、比较、OUT/SET/RST、部分 MOV/算术和 INC/DEC。其他指令保留操作数引用，但访问类型为 unknown。双字指令只列文本中写出的基地址，范围、位操作、成组软元件和索引寻址不展开。

例如 `DADD D517 K1 D500` 会写一个双字，包含 D500 的相邻字；本版本引用表只列显式的 D517、D500，不能靠查询 D501 得到完整使用情况。静态检查不执行指令、不模拟定时器、不推断扫描次序、轴运动、通信延迟或急停链。

## 调查过但未开放

- **IL → LD**：在当前固定版本的 `CreateConverter` 调用和隔离探针中，未找到经过验证的路径。枚举 0 用于现有 LD → IL；对 IL 尝试 0–8 未得到新的 LD 文件。此结论限于已调查的接口和版本，不等于证明所有版本绝无此能力。
- **IL → SFC**：原厂接口在探针中能生成 SFC 文件，但尚未通过把新块登记到工程后重新编译的等价性检查，因此未作为产品工具开放。
- **符号表、元件注释和配置结构化编辑**：现有离线代码原样保留这些文件，尚无完整格式与写回验证。不能把二进制字符串搜索当成可靠解析。
- **完整运行仿真、PLC 在线监控/下载、其他机型或版本**：不属于当前已验证工具。尤其不能用文件编译代替现场运动测试。

后续适配以可复现验证为准，不靠工具数量或名称宣称支持。
