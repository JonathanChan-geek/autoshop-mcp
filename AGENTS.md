# Scope

The current phase implements a version-bound native H3U compiler and offline project MCP tools. Load vendor DLLs only in a disposable x86 child process against a fresh workspace copy. No GUI automation, injection, installation changes, or PLC connect/download/run/stop tools.

Preserve source projects and arbitrary unknown configuration bytes. Reject unsupported versions, encrypted projects and formats explicitly. A static check is not a native compile result. Native compilation requires complete fresh block intermediates, original compiler diagnostics, stable final output, and configuration integrity gates. Never publish partial or stale Output.prg files as successful compilation.
